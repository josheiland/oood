## Core question

What would make us comfortable handing an AI a task and coming back to its result?

## Working thesis

An agent's usefulness depends on the model, tools, context, permissions, feedback and verification working together. More autonomy or more agents is valuable only where it improves a real outcome enough to justify supervision and cost. This is a proposed framing, not an adopted host opinion.

## Audience starting point

Listeners know chatbots can answer questions and produce drafts. They may conflate model with agent, context with training, tool access with permission, runtime with benchmark task difficulty, or fluent explanations with verified work.

## Story arc

Proposed six-beat conversation, approximately 40-50 minutes if it earns the time; neither structure nor recorded duration is host-approved.

1. What would each host hand off, and where would they want it to stop?
2. What makes an agent different from a chatbot answer or a predefined automation?
3. How do goals, context, tools and the action/observation loop fit together? Use one running example.
4. Where would this help? Discuss one actual host result, if available, or Project Vend's failure and later improvement with limitations.
5. How much would each host trust it? Explore verification, authority, errors and net effort through the same task.
6. What should someone try first? Each host chooses a task and boundary; offer a goal/constraints/authority/completion recipe.
