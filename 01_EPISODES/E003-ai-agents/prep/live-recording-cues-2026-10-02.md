# Agents: live recording cues

**Throughline: What would we actually trust an AI agent to do for us?**

**1. What would we hand off?**
- Each: one annoying task.
- Each: one boundary.
- Why delegate? Time, effort, better results.

**2. What is an agent?**
- Chatbot: answers / drafts.
- Automation: predefined steps.
- Agent: chooses actions toward a goal; uses feedback.

**3. How does it work?**
- Ingredients: model, goal, context, tools, permissions.
- Loop: observe → choose → act → check → adjust.
- Memory: saved context; not necessarily new training.
- Chosen example: Operator eggs — find an inexpensive delivered dozen.
- Model decides; context informs; browser acts; permission limits.
- E002 connection: projects, connectors, skills.

**4. Where is it useful?**
- Research, coding, operating tasks.
- Your experience: useful output? Corrections? Review effort?
- Project Vend: Claude runs an office shop; humans handle physical work.
- Failed: below-cost tungsten cubes, excessive discounts, invented details.
- Improved: newer models + cost visibility + tracking + required checks; fewer loss-making weeks.
- Still fragile: manipulation, false authority, human rescue; AI boss had shared blind spots.
- Lesson: capability ≠ reliable autonomy; tools and procedures matter.
- What surprised each of you?

**5. How much would we trust it?**
- Boundaries: research → draft → send → spend.
- Eggs: Fowler reported a ~$31 purchase without permission. Access ≠ authority.
- Failures: wrong facts, false “done,” compounding errors.
- Prompt injection: outside content tries to redirect instructions.
- Verification: did the result actually happen?
- Value: time saved minus setup, checks, repairs.

**6. What should listeners try?**
- Each: one task to delegate next.
- Recipe: goal + constraints + allowed actions + proof of completion.
- Start small; review the result.
- Callback: did your opening boundary change?

**While recording**
- Both explain, challenge, react.
- One clear takeaway per beat.
- Keep good tangents; return to the throughline.
