# Episodes

Use one folder per episode:

```text
E001-short-slug/
├── BRIEF.md
├── RESEARCH.md
├── OUTLINE.md
├── SCRIPT.md
├── RECORDING_NOTES.md
└── PUBLISHING.md
```

Start from `templates/EPISODE_BRIEF_TEMPLATE.md`. Create only the files an episode actually needs.

## Status vocabulary

`idea` → `researching` → `outlined` → `scripted` → `ready-to-record` → `recorded` → `editing` → `scheduled` → `published`

Never advance status without confirmation or direct evidence.
