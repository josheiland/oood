# Out of Our Depth

Working repository for **Out of Our Depth**, an AI show created and hosted by Josh Eiland and Mary.

This repo is the project's explicit operational memory: current context, durable decisions, episode work, research, assets, and publishing plans. ChatGPT Project conversations provide richer history; the files here capture the clean current state that ChatGPT Work, Codex, and other collaborators should use.

## Start here

1. Read [`AGENTS.md`](AGENTS.md).
2. Read [`00_CONTEXT/PROJECT_BRIEF.md`](00_CONTEXT/PROJECT_BRIEF.md).
3. Check the newest entries in [`00_CONTEXT/DECISIONS.md`](00_CONTEXT/DECISIONS.md).
4. Review [`00_CONTEXT/OPEN_QUESTIONS.md`](00_CONTEXT/OPEN_QUESTIONS.md) before making assumptions.

## Structure

- `00_CONTEXT/` — current project brief, decisions, open questions, and sync state
- `01_EPISODES/` — episode briefs, scripts, notes, and production status
- `02_RESEARCH/` — research notes, source logs, and primers
- `03_ASSETS/` — references and manifests for brand, visual, audio, and production assets
- `04_PUBLISHING/` — launch plans, calendars, channel strategy, and performance reviews
- `99_ARCHIVE/` — superseded material retained for history
- `templates/` — reusable working templates

## Core rule

Keep the current truth concise. Record durable changes in `DECISIONS.md`; do not silently rewrite history.
