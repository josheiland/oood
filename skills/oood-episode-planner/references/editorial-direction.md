## Plan for real interaction

- Start from a situation: something one of you tried, a question you disagree about, or an actual result worth reacting to. Give the viewer enough context to enjoy the reaction.
- Use optional formats that reveal preferences: each predicts what an actual tool will do; one chooses the output they would use; both defend different approaches; one admits an overbuilt solution. Don't invent the result or predetermine the disagreement.
- Let personal details explain a choice. Mary's design taste and Josh using her rules tell us more than generic claims about customization.
- Use callbacks when they naturally recur. Avoid catchphrase quotas, scripted flirting, canned roasts, or assigning lines neither would say.
- Make the next explanation answer the question the exchange raised. The outline should support conversation, not repeatedly stop it for a lecture.
- Ask whether a stranger can understand an inside joke. Add a short setup or cut it if necessary.
