# OOOD production skills

Canonical, editable sources for four project skills. Repository discovery links live in `.agents/skills/`; Claude Code links live in `.claude/skills/`. Portable Claude upload ZIPs are generated under `exports/skills/`. Do not edit generated copies; rerun `scripts/package-oood-skills.py` after changing a source or shared reference.

| Skill | Use it for |
|---|---|
| `oood-episode-planner` | Ideas, research, entertaining outlines, recording primers, reshoot feedback |
| `oood-episode-producer` | Raw video to an actual edited master, captions, chapters, source checks, and review package |
| `oood-brand-visuals` | Popups, chapter cards, lower thirds, thumbnails, social graphics |
| `oood-release-package` | Clips, show notes, titles, descriptions, platform copy, release review |

All four preserve host chemistry, accuracy, and the supplied brand. They are workflows for an agent with tools, not a claim that a text-only model can render video. See [usage and model guide](../00_CONTEXT/production-skills-and-models.md).
