# Assets

Git is for lightweight, shareable project files—not raw video or large audio masters.

Use `ASSET_MANIFEST.md` to record the canonical location, owner, status, and usage rights for:

- logo and icon variants;
- cover and banner files;
- fonts and color definitions;
- intro/outro music;
- OBS scene collections and profiles;
- raw recordings;
- final masters;
- thumbnails and social exports.
