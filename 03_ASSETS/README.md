# Assets

Git is for lightweight, shareable files, not raw video or audio masters. [ASSET_MANIFEST.md](ASSET_MANIFEST.md) says where everything lives, including what is only in Drive.

| Folder / file | What it is |
|---|---|
| `brand-guidelines.md`, `brand-tokens.json` | Brand rules and design tokens. Read before making any graphic or public copy. |
| `intro-outro-cards/` | The recurring "Mono, Mirrored" intro/outro cards: templates, renderer and current stills. |
| `thumbnail-template/` | Mary's paired-host thumbnail format: editable SVG, config and renderer. |
| `channel-art/` | Channel icon, YouTube banner, old text icon. |
| `caption-glossary/` | Glossary and fixer for recurring caption mistakes. |
| `brand-kit/`, `brand-fonts/`, `music/` | Local only (gitignored). Brand kit source, Teachers/JetBrains Mono fonts, theme/sting/outro audio. Copies are in the Drive backup. |
