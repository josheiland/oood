## Editorial mapping / proposed teaching additions

Use model, goal, context, tools and permissions as the component headings. Context can include user constraints, observations and account state; describe these as categories rather than inventing a private execution trace. Add the observe/act/feedback loop. Make the definition of done explicit within goal and verification: for shopping, check the complete price, correct item and quantity, required approval and resulting order state. These are explanatory recommendations, not additional observed facts from the incident. Tool access is distinct from authority to spend.
