# Publishing checklist: [episode]

## Editorial

- [ ] Title accurately reflects the episode
- [ ] Description states the audience benefit
- [ ] Factual claims and links are verified
- [ ] Chapters/timestamps are correct
- [ ] Disclosures and credits are included
- [ ] Captions and names are checked

## Media

- [ ] Final video and audio pass quality control
- [ ] Audio/video synchronization checked at start, middle, and end
- [ ] Thumbnail approved
- [ ] Platform-safe crops exported
- [ ] Captions/subtitles uploaded
- [ ] Canonical master backed up outside Git

## Distribution

- [ ] YouTube
- [ ] Instagram
- [ ] TikTok
- [ ] LinkedIn
- [ ] X
- [ ] Newsletter, if applicable
- [ ] Links tested

## Learning loop

- [ ] Baseline hypothesis recorded
- [ ] 24-hour review scheduled
- [ ] 7-day review scheduled
- [ ] 28-day review scheduled
- [ ] Lessons captured in the episode's `PUBLISHING.md`
