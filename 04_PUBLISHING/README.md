# Publishing

Keep launch strategy, content calendars, channel checklists, copy, and performance reviews here.

For each published episode, record:

- canonical title and description;
- publication date and URLs;
- thumbnail version;
- clips and platform-specific posts;
- newsletter treatment;
- 24-hour, 7-day, and 28-day performance;
- what to repeat, stop, or test next.

Use `templates/PUBLISHING_CHECKLIST.md` before each release.
